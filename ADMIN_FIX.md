# ⚠️ Проблема с /admin/dashboard

## Что произошло:

Вы открыли URL `https://goodroad.su/admin/dashboard` через **Expo Go приложение**.

Но `/admin/dashboard` - это **backend HTML страница**, она должна открываться в **обычном браузере**, а не в Expo Go!

---

## ✅ Правильный способ открыть админ панели:

### 1️⃣ Веб-дашборд (с картой) - БРАУЗЕР

**Откройте в ОБЫЧНОМ БРАУЗЕРЕ (Chrome, Safari, Firefox):**

```
https://goodroad.su/admin/dashboard
```

☝️ НЕ в Expo Go, а в браузере на компьютере или телефоне!

---

### 2️⃣ Мобильная админ панель - EXPO GO

**Откройте в EXPO GO приложении:**

Способ A: Через приложение
1. Откройте Good Road в Expo Go
2. На главном экране нажмите иконку 📊 (analytics) справа вверху
3. Откроется мобильная админ панель

Способ B: Прямая ссылка в Expo Go
```
exp://goodroad.su/admin-simple
```

---

## 🎯 Сравнение:

| Панель | Где открывать | URL |
|--------|---------------|-----|
| Веб-дашборд | **Браузер** | https://goodroad.su/admin/dashboard |
| Мобильная панель | **Expo Go** | exp://goodroad.su/admin-simple |

---

## 📱 Пошаговая инструкция:

### Для веб-дашборда:
1. Откройте Chrome/Safari на компьютере или телефоне
2. Введите URL: `https://goodroad.su/admin/dashboard`
3. Увидите карту с данными

### Для мобильной панели:
1. Откройте Expo Go
2. Отсканируйте QR код или введите URL
3. На главном экране нажмите 📊 справа вверху
4. Увидите мобильную админ панель

---

## ❓ Почему так?

**Веб-дашборд** - это полноценная HTML страница с JavaScript:
- Использует Leaflet.js для карты
- Отдается backend'ом (FastAPI)
- Работает только в браузере

**Мобильная панель** - это React Native компонент:
- Использует React Native компоненты
- Часть Expo приложения
- Работает только в Expo Go
