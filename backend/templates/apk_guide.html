📦 Создание APK файлов через Expo

Полное руководство по настройке и сборке APK для приложения Good Road

🚀 Быстрый старт

Для создания APK файла приложения Good Road вам понадобится:

  • Аккаунт на expo.dev
  • Node.js и npm установленные локально
  • Исходный код приложения Good Road
💡 Совет: Expo Build Service (EAS) предоставляет бесплатный tier для персональных проектов с ограниченным количеством сборок в месяц.

☁️ Метод 1: Облачная сборка через EAS Build

Рекомендуется для большинства случаев. Expo Build Service соберет APK на своих серверах.

Шаг 1: Регистрация на Expo

  1. Зарегистрируйтесь на expo.dev/signup
  2. Подтвердите email адрес
  3. Запомните свой username и пароль для входа

Шаг 2: Установка EAS CLI

# Установка EAS CLI глобально npm install -g eas-cli # Проверка установки eas --version

Шаг 3: Вход в аккаунт Expo

# Войти в аккаунт eas login # Ввести email и пароль когда попросит

Шаг 4: Настройка проекта

В корне проекта Good Road уже создан файл eas.json со следующей конфигурацией:

{ "build": { "preview": { "android": { "buildType": "apk" } }, "production": { "android": { "buildType": "apk" } } } }

Шаг 5: Сборка APK

# Перейти в папку frontend cd /app/frontend # Запустить сборку preview APK eas build --platform android --profile preview # Или production версию eas build --platform android --profile production
⏳ Время сборки: Обычно занимает 5-15 минут. Вы получите ссылку для скачивания APK после завершения.

Шаг 6: Скачивание APK

После успешной сборки:

  1. Expo CLI покажет ссылку на скачивание APK
  2. Или зайдите на expo.dev в раздел Builds
  3. Скачайте APK файл на устройство Android
  4. Установите APK на телефон (разрешите установку из неизвестных источников)

💻 Метод 2: Локальная сборка

Для продвинутых пользователей. Требует Android Studio и Android SDK.

⚠️ Требования:
  • Android Studio установлена
  • Android SDK настроен
  • Java Development Kit (JDK) 11+
  • ~10GB свободного места на диске

Команды для локальной сборки:

# Установить зависимости cd /app/frontend npm install # Сборка локально eas build --platform android --profile preview --local # APK будет создан в папке проекта

⚙️ Конфигурация приложения (app.json)

Основные параметры для настройки в файле /app/frontend/app.json:

name

Имя приложения (Good Road)

version

Версия приложения (например, 1.0.0)

android.package

ID приложения (com.goodroad.app)

android.versionCode

Числовая версия (увеличивать при каждой сборке)

Пример конфигурации:

{ "expo": { "name": "Good Road", "slug": "good-road-frontend", "version": "1.0.0", "android": { "package": "com.goodroad.app", "versionCode": 1, "adaptiveIcon": { "foregroundImage": "./assets/adaptive-icon.png", "backgroundColor": "#ffffff" } } } }

🔐 Переменные окружения

Для подключения к production backend убедитесь, что в файле .env правильно указан URL:

EXPO_PUBLIC_BACKEND_URL=https://goodroad.su
⚠️ Важно: При локальной разработке используется другой URL. Перед сборкой APK измените его на production URL.

🔑 Подписание APK

EAS Build автоматически создаст и подпишет APK за вас. Но если нужен контроль:

Создание keystore:

# Генерация нового keystore keytool -genkeypair -v -keystore my-release-key.keystore \ -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000 # EAS может использовать ваш keystore eas credentials

🧪 Тестирование APK

  1. Скачайте APK на Android устройство
  2. Включите установку из неизвестных источников:
    Настройки → Безопасность → Неизвестные источники
  3. Откройте файл APK через файловый менеджер
  4. Установите приложение
  5. Запустите Good Road и проверьте все функции
✅ Что проверить:
  • Подключение к серверу (goodroad.su)
  • Сбор данных с GPS и акселерометра
  • Отправка данных на сервер
  • Аудио оповещения о препятствиях
  • Работа в фоновом режиме

❗ Частые проблемы и решения

1. Build failed: Invalid credentials

Решение: Выйдите и войдите заново в аккаунт Expo

eas logout eas login

2. APK не устанавливается на телефон

Решение: Разрешите установку из неизвестных источников в настройках Android

3. Приложение не подключается к серверу

Решение: Проверьте переменную EXPO_PUBLIC_BACKEND_URL в .env файле

4. Build занимает слишком много времени

Решение: Подождите до 20 минут. Если долго - проверьте статус на expo.dev/builds

📋 Быстрые команды

Скопируйте эти команды для быстрого создания APK:

Полный процесс сборки:

# 1. Установка EAS CLI npm install -g eas-cli # 2. Вход в аккаунт eas login # 3. Переход в папку проекта cd /app/frontend # 4. Сборка preview APK eas build --platform android --profile preview # 5. Или production APK eas build --platform android --profile production
