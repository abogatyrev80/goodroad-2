🖥️ HTML Панели управления

GET /api/admin HTML
Главная страница навигации со всеми админ панелями
GET /api/admin/dashboard/v2 V2 HTML
Основная панель управления с визуализацией событий на карте и аналитикой (новая архитектура)
GET /api/admin/settings/v2 V2 HTML
Настройки ML чувствительности и очистка базы данных с фильтром по датам
GET /api/admin/dashboard Legacy HTML
Оригинальная панель управления для старой архитектуры данных
GET /expo-qr HTML
Страница с QR кодами для подключения к Expo Go

📊 Аналитика и Данные V2 (Новая архитектура)

GET /api/admin/v2/analytics V2
Получить общую статистику и аналитику событий (raw_sensor_data, events)
GET /api/admin/v2/raw-data V2
Получить сырые данные с акселерометра и GPS (поддерживает пагинацию: limit, skip)
GET /api/admin/v2/events V2
Получить классифицированные события (pothole, braking, vibration, user reports)
GET /api/admin/v2/heatmap V2
Получить данные для тепловой карты событий

⚙️ Настройки ML (V2)

GET /api/admin/v2/ml-thresholds V2
Получить текущие пороговые значения для ML классификации
POST /api/admin/v2/ml-thresholds V2
Обновить пороговые значения ML (pothole_threshold, braking_threshold, vibration_threshold, speed_bump_threshold)

✏️ Управление событиями (V2)

PUT /api/admin/v2/events/{event_id} V2
Редактировать существующее событие (тип, severity, координаты)
DELETE /api/admin/v2/events/{event_id} V2
Удалить конкретное событие по ID
DELETE /api/admin/v2/raw-data/{data_id} V2
Удалить конкретную запись сырых данных по ID

🗑️ Очистка базы данных

DELETE /api/admin/clear-database-v2 С фильтром дат
Очистка БД с возможностью указания диапазона дат
?confirm=CONFIRM&date_from=2025-01-01&date_to=2025-01-31
Удаляет данные из 8 коллекций: raw_sensor_data, events, processed_events, user_warnings, road_conditions, road_warnings, sensor_data, calibration_profiles
DELETE /api/admin/clear-database Legacy
Полная очистка базы данных (старая версия без фильтра)
DELETE /api/admin/cleanup-test-data
Удалить тестовые данные (с device_id содержащим "test")
DELETE /api/admin/cleanup-zero-coords
Удалить записи с нулевыми координатами (lat=0, lon=0)

📈 Legacy API (Старая архитектура)

GET /api/admin/sensor-data Legacy
Получить данные из старой коллекции sensor_data
GET /api/admin/analytics Legacy
Статистика для старой архитектуры
GET /api/admin/heatmap-data Legacy
Данные тепловой карты для старой архитектуры
PATCH /api/admin/sensor-data/{point_id} Legacy
Редактировать точку данных в старой коллекции
DELETE /api/admin/sensor-data/{point_id} Legacy
Удалить точку данных из старой коллекции
POST /api/admin/sensor-data/count-by-filters Legacy
Подсчет записей с фильтрами
DELETE /api/admin/sensor-data/bulk Legacy
Массовое удаление записей

📤 Экспорт и Импорт

GET /api/admin/sensor-data/export/csv
Экспорт данных в CSV формат
POST /api/admin/sensor-data/import/csv
Импорт данных из CSV файла
