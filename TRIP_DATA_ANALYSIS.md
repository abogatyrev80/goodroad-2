## ⚠️ Обнаруженные проблемы

### Проблема 1: user_reported = false
**Ожидалось:** `user_reported: true` (пользователь вручную отметил)  
**Фактически:** `user_reported: false`

**Причина:**
Backend на production использует старый код без обновленной обработки поля `userReported`.

**Влияние:**
- Невозможно отличить пользовательские отметки от автоматических
- Не работает механизм устаревания для пользовательских аварий

---

### Проблема 2: expires_at = null
**Ожидалось:** `expires_at: "2025-11-12T01:48:30"` (timestamp + 4 часа)  
**Фактически:** `expires_at: null`

**Причина:**
Старый код backend не создает `expires_at` для пользовательских отметок.

**Влияние:**
- Аварии не устаревают автоматически
- Будут накапливаться старые данные
- Cron-задача очистки не сработает

---

### Проблема 3: Отсутствие rawData
**Наблюдение:**
В sensor_data записях нет поля `rawData` с детальной информацией о событиях.

**Причина:**
Production использует старую версию backend без сохранения rawData.

**Влияние:**
- Невозможно анализировать детали событий
- Нет информации о accelerometer данных
- Ограниченная отладка
