# 📊 Доступ к панелям администратора

## 🎯 У вас есть ДВЕ админ панели:

---

## 1️⃣ Мобильная админ панель (React Native)

### Где находится:
`/app/frontend/app/admin-simple.tsx`

### Как открыть:

**Способ A: Через приложение (рекомендуется)**
1. Откройте приложение в Expo Go
2. В правом верхнем углу найдите иконку 📊 (analytics)
3. Нажмите на неё
4. Откроется мобильная админ панель

**Способ B: Прямая ссылка**
```
Preview: exp://goodroad.su/admin-simple
Deploy: exp://goodroad.su/admin-simple
```

### Функции мобильной панели:
- ✅ Статистика данных
- ✅ Управление звуковыми алертами
- ✅ Настройки приложения
- ✅ Переход к sound-settings

---

## 2️⃣ Веб-дашборд (HTML + Leaflet карта)

### Где находится:
`/app/backend/server.py` - endpoint `/admin/dashboard`

### Как открыть:

**Preview (⚠️ Требует особого routing):**
```
http://localhost:8001/admin/dashboard (локально)
```

Preview через `/api` prefix может не работать из-за Expo Router.

**Deploy (✅ Работает):**
```
https://goodroad.su/admin/dashboard
```

### Функции веб-дашборда:
- ✅ Интерактивная карта с точками данных
- ✅ Heatmap опасных участков
- ✅ Фильтры по типам событий
- ✅ Статистика в реальном времени
- ✅ Управление записями (редактирование, удаление)
- ✅ Экспорт данных

---

---

## 🔧 Как настроить доступ к веб-дашборду через Preview:

Если нужен веб-дашборд в Preview, есть варианты:

### Вариант 1: Локальный доступ
```bash
# Открыть в браузере:
http://localhost:8001/admin/dashboard
```

### Вариант 2: Прокси через ngrok (для внешнего доступа)
```bash
ngrok http 8001
# Получите URL вида: https://xxxx.ngrok.io/admin/dashboard
```

### Вариант 3: Использовать Deploy
После Re-Deploy веб-дашборд будет доступен напрямую:
```
https://goodroad.su/admin/dashboard
```
